Cole o link do anúncio no Airbnb (ex: airbnb.com.br/rooms/12345678). Ele entra na próxima atualização diária — ou clique em "Atualizar agora" nas Configurações para forçar já.

Configurações

Este portal é um site estático — para adicionar/remover imóveis ou forçar uma atualização, ele grava direto no seu repositório GitHub usando um token de acesso pessoal (fine-grained), salvo apenas neste navegador (localStorage), nunca enviado a mais ninguém.
